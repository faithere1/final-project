### **ACL Simulator v3.0: The Sentinel & Academy Update**
*(Sentinel = The Testing "Safety Net" | Academy = The "Zero to Hero" Lab Dashboard)*

#### **Phase 3.1: The Sentinel (Software Assurance)**
*Goal: Build the "Safety Net" so future versions don't break the old ones.*
*   **3.1.1 - JUnit 5 Infrastructure:** Setting up the automated testing environment in Maven.
*   **3.1.2 - Logic Unit Testing:** Automated verification of IP math, CIDR, Wildcards, and Port Ranges.
*   **3.1.3 - Regression Protection:** "Stress testing" the engine to ensure complex rulesets don't crash the app. (skipped because we need to touch our main database engine which can be dangerous.)

#### **Phase 3.2: The Academy Engine (LMS Logic)**
*Goal: The hidden "Brain" that knows how to grade a student.*
*   **3.2.1 - Lab Scenario Model:** Defining how a mission is stored (Instructions + Secret Test Packets).
*   **3.2.2 - Validation Engine (Auto-Grader):** The logic that compares the user's result against the "Key."
*   **3.2.3 - The Success Logic:** Handling what happens when a user passes (unlocking the next level).

#### **Phase 3.3: The Academy Extension (UI Dashboard)**
*Goal: The student's "Home Base."*
*   **3.3.1 - Lab Selector Window:** A new JavaFX extension to browse the 10 "Zero to Hero" levels.
*   **3.3.2 - Mission Control Sidebar:** A slide-out panel that shows the current lab instructions while the user is working on their rules.
*   **3.3.3 - Progress Persistence:** Saving "Completed" status and scores in the SQLite database.

#### **Phase 3.4: The Mentor System (User Guidance)**
*Goal: Making the Academy feel like a real teacher.*
*   **3.4.1 - Intelligent Hint System:** Logic that analyzes a failed lab and gives a hint (e.g., *"Check your Rule #10; it might be too broad!"*).
*   **3.4.2 - Lab Completion Reports:** Generating a summary of how the student performed (Time taken, number of attempts).
*   **3.4.3 - Lab-to-Sim Integration:** Auto Filler that auto fills simulation test panel with current lab test packet details.

* **3.4.4(unplanned) - Lab Reset and Save Progress**
