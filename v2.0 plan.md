# Project Improvements & Future Roadmap: ACL Simulator v2.0

This document outlines the planned technical and visual enhancements to transition the ACL Simulator from a capstone prototype to a professional-grade network utility.

## 2.1 Advanced Networking Logic
- **2.1.1 - CIDR & Subnet Matching:** Move beyond exact string matching to bitwise logic. Support matching packets against CIDR notation (e.g., `192.168.1.0/24`) to simulate real-world subnet filtering.
- **2.1.2 - Port Ranges:** Expand the port filtering logic to support ranges (e.g., `1024-65535`) rather than single integers.
- **2.1.3 - Rule Editing (Full CRUD):** Implement an "Edit Selected" feature. This allows users to modify existing rules via the dialog window and save changes using SQL `UPDATE` statements, maintaining the rule's original ID.
- **2.1.4 - Wildcard Masking:** Support Cisco-style wildcard masks (inverse masks) for advanced network matching.
- **2.1.5 - ICMP Type Filtering:** Add specific matching for ICMP types (e.g., allowing "Echo Request" for pings but blocking other control messages).

## 2.2 Interactive Visuals & Topography
- **2.2.1 - Visual Network Topology:** A dedicated canvas showing a logical map: [Source PC] --- [Router] --- [Destination].
- **2.2.2 - Packet Flow Animation:** Use JavaFX `TranslateTransition` to animate a "packet" (a colored circle) moving across the topology.
    - **Permit Animation:** Packet travels from Source, through the Router, to the Destination.
    - **Deny Animation:** Packet travels to the Router and is visually "dropped" or replaced with a red "X".
- **2.2.3 - Match Highlighting:** Real-time visual feedback where the triggered rule in the TableView glows or changes color during the simulation.

## 2.3 Advanced Features & Data Handling
- **2.3.1 - Simulation Logging:** Implement a `simulation_history` database table to record every test performed, creating a searchable audit trail of network security tests.
- **2.3.2 - Export/Import (CSV/JSON):** Allow users to export their ACL configuration to JSON or CSV files for backup, or import rulesets provided by other administrators.
- **2.3.3 - Cisco CLI Generator:** A tool to "Convert to CLI," generating the actual Cisco IOS commands (e.g., `access-list 101 permit tcp...`) based on the GUI rules.
- **2.3.4 - Batch Testing:** Ability to upload a list of multiple packets to verify an entire security policy in one click.

## 2.4 UI/UX Enhancements
- **2.4.1 - Drag-and-Drop Reordering:** Enable users to click and drag rows within the table to change rule priority. The app would then automatically re-calculate and update priority values in the SQLite database.
- **2.4.2 - Real-time Input Validation:** Advanced RegEx validation that provides visual feedback (red/green borders) as the user types IP addresses in the dialog.
- **2.4.3 - Dark Mode Support:** A CSS-based theme toggle to switch between the standard light interface and a high-contrast dark mode for network operations centers.
- **2.4.3.4 - Clear All Confirmation:** A safety mechanism to prevent accidental deletion of entire rulesets.
