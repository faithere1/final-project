# ACL Simulator v5.0 Quick Start

This folder contains the packaged ACL Simulator desktop app.

## Requirements

- Java 17 or newer

## macOS / Linux

```bash
./run.sh
```

If the script is not executable:

```bash
chmod +x run.sh
./run.sh
```

## Windows

Double-click `run.bat`, or run:

```bat
run.bat
```

## Manual Launch

```bash
java -jar ACLSimulator.jar
```

The app creates `acl_simulator.db` beside the JAR when it starts.
